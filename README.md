# Skills

[![skills.sh](https://skills.sh/b/infituit/skills)](https://skills.sh/infituit/skills)

## 目录分类

- `skills/`：对外提供的业务 skills，供使用者安装和复用；`skills.sh.json` 维护其展示分组。
- `.agents/skills/`：本仓库自用 skills，服务仓库维护与贡献流程，不纳入业务 skills 的展示分组。
- `.github/`：本仓库的 Issue / PR 模板与 GitHub 配置。

本仓库的 Issue 整理使用 `skills-repo-issue-from-idea`，PR 准备与提交使用 `skills-repo-create-github-pr`；二者均位于 `.agents/skills/` 并以当前 `.github/` 模板为准。
